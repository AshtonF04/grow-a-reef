# Asset Manifest

Things the code depends on that live **only in the Studio place file** (not in git).
Any PR that adds or changes a Studio-only instance must update this table.

Most Studio-only content is **generated by builder scripts in `tools/worldgen/`** (synced by Rojo to
`ServerStorage/WorldGen`, which never runs on its own or replicates). To rebuild, run in the Edit-mode command bar:

```lua
local f = game.ServerStorage.WorldGen:Clone() f.Parent = game.ServerStorage require(f.BuildWorld) f:Destroy()
```

## Studio backups

`tools/backup/receiver.py` + `tools/backup/Backup.luau` save every service to `studio_backup/<Service>.rbxm`
(git-ignored). Start the receiver (`python3 tools/backup/receiver.py`), then run `Backup.luau` in the Edit-mode
command bar. Restore by dragging an `.rbxm` into its service.

## Code-built screens (not Studio instances)

`HUD`, `PlantTray` and `Shop` ScreenGuis are created at runtime by `HUDController`, `PlantTrayController`
and `ShopController`; fish and kelp sway come from `AmbientController`. Nothing to build in Studio.
